# Open Sans Self-Hosted Fonts — Azure Blob Storage

## Cloud Readiness Fix: cr-css-1000

This directory holds the self-hosted Open Sans font files that replace the
insecure `@import url('http://fonts.googleapis.com/css?family=Open+Sans:400,700')`
that was previously in `assets/css/demo.css`.

## Required Font Files

Place the following font files in this directory before deploying:

| File | Weight | Style | Source |
|------|--------|-------|--------|
| `open-sans-v40-latin-regular.woff2` | 400 | normal | https://fonts.gstatic.com/s/opensans/ |
| `open-sans-v40-latin-regular.woff`  | 400 | normal | https://fonts.gstatic.com/s/opensans/ |
| `open-sans-v40-latin-700.woff2`     | 700 | normal | https://fonts.gstatic.com/s/opensans/ |
| `open-sans-v40-latin-700.woff`      | 700 | normal | https://fonts.gstatic.com/s/opensans/ |

## Azure Blob Storage Upload

Upload these files to your Azure Blob Storage `$web` container:

```bash
az storage blob upload-batch \
  --account-name $AZURE_STORAGE_ACCOUNT \
  --destination '$web/assets/fonts/open-sans' \
  --source ./assets/fonts/open-sans \
  --auth-mode login
```

## Azure CDN

After upload, the fonts will be served via Azure CDN at:
`https://<cdn-endpoint>.azureedge.net/assets/fonts/open-sans/<filename>`

Update the `@font-face` src URLs in `assets/css/demo.css` to use the CDN endpoint
once it is provisioned.

## SRI Hash Generation

SRI hashes for the font CSS are generated by the Azure DevOps pipeline.
See `assets/sri-manifest.json` for the full pipeline configuration.
